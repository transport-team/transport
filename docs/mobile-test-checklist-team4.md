## 7. 터널·HTTPS 설정 확인

| 항목 | 확인 방법 | 기대 결과 | 상태 |
|------|-----------|-----------|------|
| **ngrok/Cloudflare Tunnel 실행** | `ngrok http 5173` 또는 Cloudflare Tunnel | `https://xxx.ngrok-free.app` 또는 `https://xxx.trycloudflare.com` 접속 가능 | [ ] |
| **휴대폰에서 HTTPS 접속** | 휴대폰 브라우저로 터널 URL 열기 | 인증서 경고 없음, 페이지 정상 로드 | [ ] |
| **위치 권한 프롬프트** | 기사 처리 화면 진입(IN_TRANSIT) | 브라우저 위치 권한 허용 팝업 표시 | [ ] |
| **카카오맵 키** | `VITE_KAKAO_JS_KEY` 설정된 `.env.local` | 지도 정상 로드, 콘솔 키 에러 없음 | [ ] |
| **CORS** | 백엔드 8080, 프론트 터널 URL | `Access-Control-Allow-Origin`에 터널 origin 허용 또는 `*` | [ ] |
| **쿠키/인증** | `Secure; SameSite=None` 쿠키 | HTTPS에서 쿠키 전송·인증 정상 | [ ] |

## 8. 시연 스크립트 (3분 발표용)

```
1. 기사 폰: /driver/dispatches/:id 진입 → 화물/수령인/전화 확인
2. 기사 폰: 상차 사진 촬영(후면 카메라) → 업로드 → "상차 완료 처리"
3. 기사 폰: "운송 시작" → 위치 공유 배지(녹색) 확인
4. 고객 폰: 배송 상세 → 타임라인(상차완료 기록) → 지도(기사 마커 실시간 이동)
5. 기사 폰: "도착 처리" → "배송 완료 처리"(인수증 사진)
6. 고객 폰: 완료 → 리뷰 작성(별점+후기) → 평균 평점 확인
7. 헤더 종: 새 알림 토스트(배차/상태변경/리뷰요청) → 클릭→읽음→이동
8. 기사 폰: 완료 후 지도 숨김(개인정보) 확인
```
