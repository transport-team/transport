# 요구사항 정의

- 구분: **핵심** = MVP(6주차)에 꼭 필요 / **확장** = MVP 이후
- 담당: 1 공통·인증·운영 / 2 기사·차량·배차·정산 / 3 배송·운임·결제 / 4 진행·실시간·리뷰
- 범위 제외: 실제 결제(라이브 키), 네이티브 앱, 여러 경유지 배송, 공휴일 할증, 기업 계약 단가, 프로모션·배너

## 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 보안 | BCrypt, 역할별 접근 제어, 배송 상세는 본인·배정 기사·관리자만, 키는 설정 파일·환경변수 |
| 결제 안전 | 운임은 서버만 계산, 승인 전 금액 비교, 승인 후 저장 실패 시 결제 취소 |
| 개인정보 | 기사 위치는 운송중에만 수집·표시, 완료 후 숨김, 30일 지난 기록 삭제 |
| 무결성 | 허용된 상태 전이만, 동시 배차·상태 변경 방지(@Version) |
| 성능 | 페이징(기본 10), N+1 방지, 같은 구간 거리 재사용, 위치 30초 간격 |
| 사용성 | 기사 화면 모바일 우선, 로딩·빈 목록·에러 표시, 금액 쉼표 |
| 시간대 | 서버·DB·JDBC 모두 Asia/Seoul, LocalDateTime |
| 협업 | 모든 코드 PR 리뷰 1명 승인 후 병합, develop은 항상 실행 가능 |
