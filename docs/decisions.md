# 결정 기록

팀이 정한 것을 한 줄씩 남긴다. "왜 이렇게 했지?" 논쟁을 줄이고 발표 자료가 된다.

| 날짜 | 결정 | 이유 |
|---|---|---|
| 2026-11-02 | Spring Boot 4.1.2 · Java 21로 통일 | 팀원 전원 JDK 21, 최신 버전 지원 기간이 김. 수업 코드는 구조만 참고 | 교수님 코드와 비교 · Boot 4는 Security 7 · Jackson 3 등이 바뀌어 예제 호환 문제 |
| 2026-11-02 | 저장소는 backend/ · frontend/를 담은 모노레포 | 도메인별로 백엔드 · 프론트를 한 PR에서 함께 수정 |
| 2026-11-02 | DB는 각자 로컬(Docker MariaDB), 시드는 data.sql로 공유 | 공용 DB는 ddl-auto 변경 · 데이터 충돌로 서로를 깨뜨림 |
| 2026-11-02 | 결제는 토스페이먼츠 테스트 키 · 결제창(API 개별 연동 키) | 계약 없이 테스트 가능, 실제 결제 없음 |
| 2026-11-02 | 배송 상태에 결제대기(PENDING_PAYMENT) 추가 | 결제 전 신청서 저장 · 금액 검증 · 30분 자동 취소 |
| 2026-11-02 | 배포는 HTTPS 필수, 1차 배포 8주차 | 브라우저 위치 API는 HTTPS · localhost에서만 동작 |
| 2026-11-03 | 자바 · gradle 들여쓰기는 탭 (.editorconfig) | 기존 자바 파일 대부분이 탭, IDE 재정렬로 파일 전체가 바뀌는 충돌 방지 |
| 2026-11-03 | 서비스는 interface + Impl (수업 방식), 비밀번호 8자 이상 | 수업 코드와 같은 구조로 설명 · 리뷰가 쉬움 |
| 2026-11-03 | 로그인은 JSON API(`POST /api/auth/login`) + JWT, 수업의 formLogin은 쓰지 않음 | React 화면 · api.md 명세와 맞춤, 서버 세션 없음 |
| 2026-11-03 | 토큰: 액세스 30분 · 리프레시 1일, 재발급 때 둘 다 새로 발급 | 사용 중 끊김을 줄이고 리프레시 토큰을 오래 쓰지 않게 |
| 2026-11-03 | 권한 전환일 전까지 토큰 없는 요청은 통과, 잘못되거나 만료된 토큰만 401 | 로그인 기능이 들어가도 팀원 개발 · 테스트가 깨지지 않게 |
